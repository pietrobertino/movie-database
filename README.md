## MOVIE DATABASE

Web app for browsing a movie database, where users can click a movie poster to access its details, read reviews, and leave their own. Built with a React frontend and an Express backend, with a database created in MySQL.

## How to import the project

1) Create your own .env files (for both backend and frontend) following the example files provided (.env.example)

2) Run the following instructions on a split terminal:

First terminal:

cd frontend

npm i 

npm run dev


Second terminal:

cd backend

npm i 

npm run dev
